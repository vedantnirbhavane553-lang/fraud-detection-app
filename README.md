# 💳 Online Payment Fraud Detection System

An end-to-end Machine Learning web application built using **Python**, **Scikit-Learn**, and **Streamlit** to predict whether an online financial transaction is legitimate or fraudulent in real-time.

---

## 📌 Project Overview
Online financial fraud causes substantial losses worldwide. This project utilizes a trained **Random Forest Classifier** to analyze transaction patterns—such as transaction type, transfer amount, sender balance, and receiver balance—and classifies them into **Legitimate** or **Fraudulent** transactions.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Web Framework:** Streamlit
* **ML Algorithms:** Random Forest (Scikit-Learn)
* **Data Manipulation:** Pandas, NumPy
* **Version Control:** Git LFS (for `.pkl` model tracking)
